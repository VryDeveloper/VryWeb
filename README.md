# VryDeveloper - Portfólio Pessoal

![VryDeveloper Logo](assets/iconvictor.png)

## 📝 Sobre o Projeto

Este é meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e experiências como desenvolvedor. O site foi criado com foco em design moderno, responsividade e experiência do usuário.

## 🚀 Funcionalidades

- **Design Responsivo**: Adaptável a diferentes tamanhos de tela
- **Tema Claro/Escuro**: Alternância entre temas para melhor experiência visual
- **Animações Suaves**: Transições e efeitos visuais para melhor engajamento
- **Visualização de Projetos**: Alternância entre visualização em grade e lista
- **Integração com GitHub**: Exibição de estatísticas e atividades recentes
- **Seção de Habilidades**: Apresentação organizada das tecnologias dominadas
- **Botão de WhatsApp**: Contato rápido via WhatsApp
- **Download de CV**: Acesso fácil ao currículo
- **Links para Redes Sociais**: Conexão com perfis profissionais

O site é totalmente responsivo e se adapta aos seguintes breakpoints:
- Desktop: > 1020px
- Tablet: 768px - 1020px
- Mobile: < 768px

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/VryDeveloper/VryWeb.git
```

2. Navegue até o diretório do projeto:
```bash
cd VryWeb
```

3. Abra o arquivo `index.html` em seu navegador ou utilize um servidor local.
